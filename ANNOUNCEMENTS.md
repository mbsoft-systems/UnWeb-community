## 2026-03-12 — UnWeb Launch

UnWeb is live! The HTML-to-Markdown conversion platform is now available at [unweb.info](https://unweb.info).

**What's available:**
- API at [api.unweb.info](https://api.unweb.info) with free tier (100 conversions/month)
- Dashboard at [app.unweb.info](https://app.unweb.info) for API key management and usage tracking
- CLI for Windows, macOS, and Linux — download from [Releases](https://github.com/mbsoft-systems/unweb-community/releases)
- Documentation at [docs.unweb.info](https://docs.unweb.info)

**Coming soon:**
- Chrome and Firefox browser extensions
- n8n, Make, and Zapier integration templates
