# JavaScript Examples

Node.js scripts for using the UnWeb API.

## Examples

| Script | Description |
|--------|-------------|
| [basic-convert.js](basic-convert.js) | Convert HTML or a URL to markdown |

## Usage

Set your API key as an environment variable:

```bash
export UNWEB_API_KEY="unweb_your_key_here"
```

Then run:

```bash
node basic-convert.js
```

No dependencies required — uses the built-in `fetch` API (Node.js 18+).
